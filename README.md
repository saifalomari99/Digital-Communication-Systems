## Overview

This repository contains engineering projects exploring the design, modeling, simulation, and analysis of digital communication systems. Each project builds a transmitter and receiver chain in software, runs it under controlled conditions, and documents what the resulting waveforms show about the underlying system.

The current work is MATLAB based and focuses on signal processing for modulation, carrier synchronization, signal recovery, and receiver architectures. Every result in this repository comes from simulation. No hardware implementation is included, and the project write-ups state this explicitly where it matters.
